# Hola, soy Luiz

Estudio el Máster en Ciencias Actuariales y Financieras (Universidad de Alcalá) y convierto cada asignatura en guías de estudio, simulaciones y un atlas 3D. Todo en abierto y en español.

**Todo, en un sitio: [luizluzuriaga.github.io](https://luizluzuriaga.github.io/)**

| Proyecto | Qué es |
|---|---|
| [Gedankenpalast](https://github.com/LuizLuzuriaga/Gedankenpalast) | Atlas 3D de estudio actuarial y cuantitativo, con una guía dentro de cada asignatura |
| [Simulación y modelos](https://luizluzuriaga.github.io/Gedankenpalast/Fundacion/guias/simulacion.html) | Guía de estudio: generación de variables, Monte Carlo, regresión, Ridge, LASSO y Elastic Net |
| [Estadística bayesiana](https://luizluzuriaga.github.io/Gedankenpalast/Fundacion/guias/bayesiana.html) | Guía de estudio con laboratorios interactivos |
| [Previsión social](https://luizluzuriaga.github.io/Gedankenpalast/Fundacion/guias/prevision_social.html) | Guía de estudio con líneas temporales |
| [Seguridad Social](https://github.com/LuizLuzuriaga/asignaturas) | Tests de práctica: 64 preguntas, 19 casos y 5 ejercicios de cálculo |
| [Portfolio actuarial](https://github.com/LuizLuzuriaga/Actuariales) | Portfolio como habitación interactiva con minijuegos |
